# Air Quality Analysis Project

**Student:** Alberto Ruiz

## Project Overview

This project uses Python to analyze air quality data collected in Italy from 2004 to 2005. The goal is to explore pollution measurements, create visualizations, and develop regression and classification models.

## Dataset

The dataset comes from the UCI Machine Learning Repository. It contains air pollution measurements along with temperature and humidity information.

## Software and Libraries

- Google Colab
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run the Program

1. Open the Python notebook in Google Colab.
2. Upload the cleaned air quality CSV file.
3. Run each code cell in order.
4. Review the graphs and model results.
5. Download the generated output files.

## Regression Model

The regression model uses linear regression to predict carbon monoxide concentration based on temperature, relative humidity, and absolute humidity.

## Classification Model

The classification model uses logistic regression to categorize carbon monoxide measurements as high or low relative to a threshold calculated from the training data.

## Generated Outputs

The project generates a carbon monoxide distribution graph, a temperature-versus-carbon-monoxide scatterplot, and a classification confusion matrix. It also prints regression and classification performance metrics.

## Conclusion

This project demonstrates how Python can be used to analyze real-world data and build predictive models. The results help show relationships between environmental measurements and air pollution.
